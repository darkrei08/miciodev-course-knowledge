# Contribution rules

- Keep notes provenance-first: every claim needs a source link and an evidence status.
- Distinguish playlist metadata, repository/code observations, and transcript-derived claims.
- Do not claim that a transcript was retrieved unless the retrieval and source are recorded.
- Preserve exact video IDs, titles, and URLs from verified sources.
- Keep raw audio, captions, and transcripts in ignored local directories (`raw/`, `private/`, or `transcripts/`).
- Add timestamps and confidence to per-video notes; mark unchecked material as pending verification.
- Prefer small Markdown or JSON changes. Do not add network downloaders or provider integrations to this repository.
- Run JSON parsing checks and inspect the rendered Markdown before proposing a change.
